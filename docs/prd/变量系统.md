# 变量系统

> **状态：提案（待 Qiio7 盖章）** ｜ 2026-11-08
> 本文是《刀剑遣流年》唯一一份变量结构文件。字段名以这里为准，ZOD schema 与变量更新规则都从这里派生。

**已定的前提**：开放世界，时间与境界都不设上限；尺度 NSFW；技术栈 MVU + ZOD。

---

## 一、参考卡实测：8 个变量根

| 根 | 字段要点 | 我们的对应 |
|---|---|---|
| 当前时间 | `日期`(字符串) `时刻`(字符串) | → 时序（改成数值） |
| 当前地点 | `名称` `区域` `环境` | → 所在 |
| 当前事件 | `当前幕` `当前幕结束标志` `结束标志状态` `本幕已结束` `当前事件` `下一个事件` `上一幕总结` `场景物品` | → 当前事（保留） |
| 战斗状态 | `是否战斗中` `当前回合` `参战角色` `行动顺序` `当前行动者` `行动额度` `上次检定` | → 交手 |
| 主角档案 | 姓名/性别/年龄/身份/势力/种族/血统/能力表/战力(基础+当前+爆发+极限)/HP/战斗负荷/兵器/掩体/状态/形态/目标/伤势/濒死/生死/成长 | → 主角 |
| 物品栏 | `{[ID]: 武器\|普通物品}` | → 行囊 |
| NPC档案 | 在场/身份/势力/外观/能力/战力/HP/负荷/随身物品/兵器/关系/好感/位置/行动/情绪/心声/距离/伤势/生死 | → 人物 |
| 蝴蝶效应 | 编号/名称/原著走向/实际走向/发生于/波及≤8/状态/收束条件 | → 恩怨 |

## 二、值得抄的 14 条

| # | 参考卡怎么做的 | 我们怎么改 | 为什么值得抄 |
|---|---|---|---|
| 1 | 物品四处互斥（物品栏 / 当前武器 / 场景物品 / NPC随身），用 `move` 原子迁移，禁止 add+remove 模拟 | 行囊 / 当前兵器 / 场景物什 / 人物随身 | 防物品复制与莫名消失的唯一可靠办法，AI 最爱在这犯 |
| 2 | 不在场 NPC 精简卡：EJS 现算，只给 在场/关系/好感/位置/生死 | 同 | 人物一多，全量档案塞上下文必爆。这是成本命门 |
| 3 | 行动额度：`主要行动/移动/防御反应` 各 0-1 | `主动/移动/拆招` 各 0-1 | 防 AI 一回合连打三招 |
| 4 | 上次检定完整留档（骰面/修正/总值/DC/依据/结果/伤害） | 同，改成 d20 | 公开骰点可回查，防 AI 自造结果 |
| 5 | 伤势独立于 HP（名称/严重度/检定影响/是否已处理） | 断骨、内伤、经脉受损 | 武侠受伤不该是掉血，是具体伤 |
| 6 | 濒死三段计数（成功/失败 0~3） | 同 | 比一骰定生死有张力 |
| 7 | 战斗负荷 0~100 | **真气**（可成长上限） | 武侠真正的资源池，比 HP 重要 |
| 8 | 与主角距离：贴身/近距/中距/远距/超远 | 同 | 距离直接决定能不能打到 |
| 9 | 幕流程：`结束标志状态` 有 有效/已失效/已达成 三态 | 同（改称「章」） | 三态是精髓——标志被破坏后要改写收束，逼 AI 承认因果断了 |
| 10 | 形态分层：常态 / 爆发态 / 极限态（独立对象，不改基础） | 常态 / 运功 / 走火 / 入魔 | 临时强化必须有独立槽，绝不能改基础境界 |
| 11 | 好感度 -200~200，九段（死敌→生死羁绊） | 同，但拆出「情谊」 | 见下文必须加的第 12 条 |
| 12 | 变量展示条目用 EJS 现算 + 注入 `<act_state>` 提示块 | 同 | 把"算"从生成挪到渲染，省钱 |
| 13 | 里程碑留档：达成目标/事件/时间/前后阶位 | 同 | 成长史可回查、可喂 UI |
| 14 | 条目命名与 order 约定：`[initvar]` / `[mvu_update]` / `[mvu_plot]` 分段占位 | 同 | 后期 40+ 条目靠它排序，不然乱 |

## 三、该删的

| 参考卡字段 | 处理 |
|---|---|
| `掩体状态` | 删。枪战概念 |
| `弹药或充能` | 留一个资源槽，改名「暗器 / 毒囊 / 符箓」数量 |
| `种族` `血统等级` `言灵` `龙王权柄` | 删。换成 `心法` `武学` `境界` |
| `蝴蝶效应`（原著走向 vs 实际走向） | 删结构，改「恩怨」 |
| 世界线 / βγ 线 | 无此设定 |

## 四、参考卡没有、我们必须加的 13 条

| # | 变量 | 为什么必须 | 没有会怎样 |
|---|---|---|---|
| 1 | **数值化日期**（年/月/日 整数 + 十二时辰枚举） | 参考卡存字符串 `2012年04月06日`，脚本算不了天数差 | "闭关三月""赶路七日""比武还有二十天"全部落不了地，时间变成嘴上说说 |
| 2 | **节令 / 岁时** | 时间感 + 天然剧情触发器 | 世界没有季节，一年和一天一样长；上元灯会、中秋聚宴这类场合无处挂 |
| 3 | **真气**（当前 / 上限 / 恢复） | 参考卡负荷上限固定 100；武侠要"越练越厚" | 练十年和练一年没区别；走火入魔没有物理载体 |
| 4 | **经脉**（状态 / 受损处 / 禁忌） | 心法锁的物理载体 | 伤只剩掉血，"少阳三焦经受损、运功打七折"这种武侠质感全丢 |
| 5 | **集团声望**（朝廷/正道/邪道/西域，各带积分与风评） | 单一"名望"必废 | 你在正道是翘楚、在邪道是死敌、在朝廷是良民，一个数字表达不了。按大集团算，不按单个门派算 |
| 6 | **通缉 / 悬赏** | 行侠仗义必然招官非 | 后果为零，世界是软的，杀人放火没人管 |
| 7 | **江湖动态**（玩家不在场时发生的事，≤8 条，带时限与"是否已知"） | 开放世界的"活"全靠它 | 世界只在你眼前动，你一转身它就停 |
| 8 | **日程 / 会期**（未来事件 + 倒计时，≤8 条） | 比武大会、武林大会、师门大比、仇家上门 | 没有赶场压力，开放世界退化成闲逛 |
| 9 | **恩怨账本**（对象 / 缘由 / 方向 / 轻重 / 了结条件） | 武侠的社交货币 | 谁欠你一条命、你欠谁一顿酒、谁记你的仇，全靠 AI 记性 |
| 10 | **门派职阶**（杂役→外门→内门→真传→执事→长老） | 参考卡"当前身份"是自由文本 | 门内晋升没有刻度，练到掌门也没个说法 |
| 11 | **年龄自动推进** | 参考卡年龄是死的 | 开放世界无时长上限，玩五年还是十六岁 |
| 12 | **情谊（与好感度分离）** | 好感是态度，情谊是关系性质 | 会出现"好感 180 但只是师徒"或"好感 -50 却已定情"的怪事。**这条对恋爱线是刚需** |
| 13 | **NPC 自带境界** | 开放世界 NPC 会成长、会死、会叛门 | 师尊永远是师尊，师妹永远打不过你，江湖不会变 |

## 五、根目录（9 根）

```
1. 时序      年/月/日/时辰/节令
2. 所在      州/具体/环境/势力
3. 当前事    章/收束标志/标志状态/本幕已结束/当前事件/下一事件/上幕总结/场景物什
4. 交手      是否交手/回合/参战/出手序/当前出手/行动额度/上次检定
5. 主角      档案 + 境界 + 真气 + 经脉 + 心法 + 武学 + 名望 + 通缉 + 破境
6. 行囊      {[ID]: 兵器|物什|秘籍|丹药}
7. 人物      {[姓名]: 完整档案（含在场/境界/好感/情谊/心声/距离）}
8. 江湖      动态[] / 日程[]
9. 恩怨      {[编号]: 对象/缘由/方向/轻重/状态/了结条件}
```

参考卡是 8 根，我们 9 根：把它的「蝴蝶效应」换成「恩怨」，再加一个「江湖」。不加更多——每多一根，每轮 token 与出错面都涨。

## 七、成本控制（照抄参考卡的三条硬办法）

1. **不在场人物只发精简卡**：主变量里保留完整档案，但每轮注入上下文时用 EJS 拆出不在场者，只留 `在场/关系/好感/情谊/位置/生死`。参考卡 44 个专属人物就是这么撑住的。
2. **静态数据不进变量**：境界表、心法表、武学表、装备价目、地图坐标全部放 `data/*.json`，由脚本或 EJS 读，不塞进 `stat_data`。
3. **能用渲染算的不要生成**：`节令`、`境界名`、`名望称号`、`战力档值` 全部脚本核算，AI 只写变化，不写推导。
