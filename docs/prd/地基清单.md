## 三、地理条目的硬规格

写在 `Source/World Lore/` 下，一条一文件，纯 txt。

| 项 | 规格 |
|---|---|
| 文件名 | 条目名.txt，与正文首行 `【条目名】` 一致 |
| 字数 | 总图 2000 以内；州府 800~1200；镇与山 700~1000；险地 600~900 |
| order | 总图 20；州府 100~130；镇与山 50~70；险地 50 |
| constant | 只有「天下总图」可以常驻，其余走关键词 |
| 关键词 | 2~4 个，必须是地名专名。**不许用「州」「山」「城」这种单字或泛称** |
| 文风 | 规范句体：写"有什么、在哪、多高多远、产什么、归谁"，不写抒情 |

### 正文骨架（照这个写，不想用就改）

```
【地名】
用途：本条目定义……的位置、形势、物产与所属。

一_方位与疆界
二_山川形势
三_气候与物产
四_人文与营生
五_江湖势力
六_关键地点
```

模板已放在 `Source/World Lore/_条目模板.txt`，抄一份改名就能填。
